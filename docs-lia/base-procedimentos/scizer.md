# Scizer

## Nome principal

Scizer

## Sinônimos e termos relacionados

A Lia deve entender como relacionados ao Scizer:

- Scizer
- gordura localizada
- gordura corporal
- abdome
- flancos
- barriga
- pneuzinho
- gordura no abdome
- gordura nos flancos
- redução de gordura
- tratamento para gordura
- criolipólise
- alternativa à criolipólise

## O que é

Scizer é uma tecnologia usada na CR Laser® para tratar gordura localizada, conforme a indicação de cada caso.

O foco principal do Scizer é gordura localizada, especialmente em regiões como abdome e flancos.

## Como a Lia deve explicar

A Lia deve explicar de forma simples:

O Scizer é uma tecnologia indicada quando a principal queixa é gordura localizada.

Ele pode ser usado em áreas como abdome e flancos, conforme a indicação de cada caso.

## Indicação principal

A Lia deve reforçar:

Scizer é indicado quando o foco principal é gordura localizada.

Quando o problema principal é flacidez ou pele sobrando, a tecnologia mais indicada pode ser outra, como Endymed ou Ultraformer MPT, conforme o caso.

## Diferença entre Scizer, Endymed e Ultraformer MPT

A Lia deve explicar de forma simples:

- Scizer: foco principal em gordura localizada.
- Endymed: foco em flacidez, pele sobrando e firmeza, especialmente quando não existe gordura importante.
- Ultraformer MPT: foco em flacidez, contorno, lifting sem cirurgia, papada e estímulo de colágeno.

## Relação com criolipólise

Quando perguntarem sobre criolipólise, a Lia não deve dizer que a CR Laser® faz criolipólise.

Resposta correta:
Na CR Laser®, quando o foco é gordura localizada, trabalhamos com Scizer, conforme a indicação de cada caso.

## Regiões comuns

A Lia pode citar como regiões comuns:

- abdome;
- flancos;
- áreas corporais com gordura localizada, conforme indicação.

## Pós-procedimento

A Lia pode dizer, de forma geral, que após o Scizer costuma ser possível manter rotina normal, conforme orientação da equipe.

Pode mencionar que atividade física leve pode ser recomendada após o procedimento, conforme orientação.

Não prometer ausência total de sintomas.

## Resultado

A Lia pode dizer que o resultado é progressivo e varia conforme o organismo, região tratada e indicação.

Não prometer resultado imediato.

## Cuidados na resposta

A Lia não deve prometer resultado.
A Lia não deve dizer que substitui emagrecimento.
A Lia não deve dizer que serve para perder peso.
A Lia não deve dizer que trata flacidez como foco principal.
A Lia não deve diagnosticar.
A Lia não deve substituir orientação profissional.
A Lia não deve afirmar que serve para todos os casos.
A Lia não deve dizer que a CR Laser® faz criolipólise.
A Lia só deve falar de preço se o paciente perguntar preço, valor, promoção, desconto ou compra.

## Respostas modelo

### Pergunta: tem Scizer?

Resposta esperada:
Sim. Na CR Laser® trabalhamos com Scizer, uma tecnologia indicada principalmente para gordura localizada, conforme a indicação de cada caso.

### Pergunta: Scizer serve para gordura?

Resposta esperada:
Sim. O Scizer é indicado quando a principal queixa é gordura localizada, especialmente em regiões como abdome e flancos, conforme o caso.

### Pergunta: Scizer serve para flacidez?

Resposta esperada:
O foco principal do Scizer não é flacidez, e sim gordura localizada. Quando a queixa principal é flacidez ou pele sobrando, pode existir outra tecnologia mais indicada, como Endymed ou Ultraformer MPT.

### Pergunta: Scizer é igual Endymed?

Resposta esperada:
Não. O Scizer tem foco principal em gordura localizada. O Endymed é mais voltado para flacidez, pele sobrando e firmeza da pele.

### Pergunta: Scizer é igual Ultraformer?

Resposta esperada:
Não são iguais. O Scizer é mais indicado para gordura localizada. O Ultraformer MPT é mais usado para flacidez, contorno, papada e estímulo de colágeno.

### Pergunta: faz criolipólise?

Resposta esperada:
Na CR Laser®, quando o foco é gordura localizada, trabalhamos com Scizer, conforme a indicação de cada caso.

### Pergunta: Scizer emagrece?

Resposta esperada:
O Scizer não é um tratamento para emagrecimento. Ele é voltado para gordura localizada, conforme a indicação de cada caso.

### Pergunta: Scizer é para abdome?

Resposta esperada:
Sim, o abdome é uma das regiões em que o Scizer pode ser indicado quando a queixa principal é gordura localizada.
