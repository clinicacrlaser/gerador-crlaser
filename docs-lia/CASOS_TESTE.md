# Casos de Teste da Lia CR Laser®

## Testes básicos

- Pergunta: tem botox
  - Resultado esperado: responder que a CR Laser® oferece Botox, com resposta curta e objetiva.
  - Status: Pendente

- Pergunta: botox fica natural
  - Resultado esperado: explicar de forma clara e objetiva que o resultado depende do protocolo e do profissional, sem prometer resultado.
  - Status: Pendente

- Pergunta: quais os pontos do botox
  - Resultado esperado: responder de forma objetiva e sem inventar detalhes não documentados.
  - Status: Pendente

- Pergunta: qual o valor do botox
  - Resultado esperado: informar preço apenas se houver informação clara e de forma objetiva; caso não haja, indicar que o valor pode ser verificado com atendimento.
  - Status: Pendente

- Pergunta: quero agendar botox
  - Resultado esperado: direcionar para WhatsApp ou atendimento humano, conforme regra de fluxo.
  - Status: Pendente

## Testes de Ultraformer MPT

- Pergunta: tem mpt?
  - Resultado esperado: responder que a CR Laser® oferece Ultraformer MPT.
  - Status: Pendente

- Pergunta: tem ultraformer?
  - Resultado esperado: direcionar para Ultraformer MPT como opção da CR Laser®.
  - Status: Pendente

- Pergunta: tem liftera?
  - Resultado esperado: responder que a CR Laser® trabalha com Ultraformer MPT e não usar o termo Liftera como procedimento próprio.
  - Status: Pendente

- Pergunta: tem hifu?
  - Resultado esperado: responder de forma objetiva, direcionando para Ultraformer MPT.
  - Status: Pendente

- Pergunta: ultrassom microfocado é o mesmo que mpt?
  - Resultado esperado: explicar de forma simples que a Lia direciona esse tipo de dúvida para Ultraformer MPT.
  - Status: Pendente

## Testes de procedimentos proibidos ou substitutos

- Pergunta: tem sculptra?
  - Resultado esperado: informar que a CR Laser® não oferece Sculptra e, quando fizer sentido, explicar sobre Bioestimulador Diamond.
  - Status: Pendente

- Pergunta: tem pmma?
  - Resultado esperado: responder de forma clara que a CR Laser® não oferece PMMA e não recomendar.
  - Status: Pendente

- Pergunta: faz rinomodelação?
  - Resultado esperado: informar que a CR Laser® não oferece rinomodelação como procedimento próprio.
  - Status: Pendente

- Pergunta: faz fio de pdo?
  - Resultado esperado: direcionar para tecnologias de flacidez quando fizer sentido, sem apresentar como procedimento da CR Laser®.
  - Status: Pendente

- Pergunta: faz criolipólise?
  - Resultado esperado: direcionar para Scizer quando o foco for gordura localizada.
  - Status: Pendente
